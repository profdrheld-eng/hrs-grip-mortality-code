# Use and reproducibility

Code is distributed under MIT; HRS data remain subject to their access conditions. Use the corrected implementation. Historical snapshots support traceability and are not alternative current results; source-identity guards must remain enabled.

Tests use artificial data and released aggregates. They do not replace reproduction of participant-level analyses in an authorized local environment. No automatic cloud analysis or dependency installation is configured.

Cite the fixed GitHub version identified in the manuscript. No separate code DOI has been assigned.
